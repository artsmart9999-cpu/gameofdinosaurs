# Dominators — аналог (Canvas)

Упрощённый аналог [Dominators: Fighting Dinosaurs](https://www.crazygames.com/game/dominators-fighting-dinosaurs-fyf).

## Запуск на другом компьютере

Скопируйте папку игры целиком и откройте в ней `index.html` двойным щелчком. Рядом с `index.html` должны лежать:

- `css/` — оформление страницы
- `js/` — логика игры
- `assets/heroes/`, `assets/enemies/`, `assets/bg/` — картинки героев, врагов и фонов

`tools/` для игры не нужен. Монеты, открытые уровни и прокачка хранятся в браузере, а не в папке, поэтому на новом компьютере сохранение начнётся заново. Внешний вид, локации и управление остаются теми же.

Локальный сервер по желанию:

```bash
cd "J:\база игры"
npx serve .
```

После смены спрайтов — **Ctrl+F5**.

## Управление

**Меню:** `<<` / `>>` дино · Броня / Урон / Темп · оружие `<` `>` + апгрейд · скилл `<` `>` + апгрейд · Играть

**Бой:**

| Действие | Клавиши |
|----------|---------|
| Ходьба | A / D |
| Прыжок | W / ↑ |
| Полёт | второй W / ↑ в воздухе (в течение ~0.28 с) |
| Вниз в полёте | S / ↓ |
| Стрельба | мышь + ЛКМ (выбранное оружие) |
| Скилл | Пробел (выбранный скилл) |
| Пауза | Esc |

Полёт сбрасывается при касании земли.

## Локации и звук

Три биома по кругу после побед: **Равнины** → **Ущелье** → **Вулкан** (`levelsCleared % 3`).  
В бою — parallax-фон, тинт неба, процедурные облака и частицы по биому.  
В **Ущелье** — процедурный водопад. В ангаре: «Пройдено» и следующая локация.  
SFX и ambient через Web Audio (без MP3); звук включается после первого клика «Играть».

## Прокачка, оружие и скиллы

В ангаре три раздельных апгрейда (~10% к целевому стату): **Броня**, **Урон**, **Темп**.  

Оружие: **Бластер** (универсал) / **Дробовик** (силён против rushers и толпы) / **Рельса** (сильна против tank / spitter / босса).  
Качается отдельно кнопкой «Апгрейд».  

Скиллы на Пробел: **Молния** (конус) / **Щит-импульс** (неуязвимость + хил) / **Ракета** (AoE по курсору) — выбор и апгрейд в ангаре.

В бою: грант, рывок, зигзаг, плевун, пикировщик, танк.  
Четыре волны + босс **Тиран** (~92% прогресса); убийство босса даёт монеты и +1 уровень оружия.
